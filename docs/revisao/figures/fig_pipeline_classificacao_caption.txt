FIGURA 2 — Pipeline de classificação de anomalias

Legenda (caption):
Pipeline de classificação do NOC Lite. A coleta (ping/TCP/HTTP/DNS/SNMP) alimenta
extract_features_from_db (janela de 5 min), cujo dicionário de features é convertido
em snapshot textual por tokenise_metrics. Três classificadores operam sobre a mesma
entrada de forma paralela: (i) Heurístico baseado em limiares estáticos;
(ii) Machine Learning (DecisionTree treinada com dados 100% sintéticos); e
(iii) IA Generativa (Gemini 1.5 Flash, LLM fechado). A saída é um JSON com a
classificação. Thresholds-chave da heurística: net_in > 50 Mbps & cpu > 75% →
DDOS_ATTACK; net_out > 50 Mbps → DATA_EXFILTRATION; failed_tcp_ports ≥ 3 →
PORT_SCAN; ping_latency > 120 ms → NETWORK_CONGESTION; ping=0 & tcp=0 → HOST_DOWN.
Os três classificadores são consumidos apenas por GET /api/anomalies/classify,
fora do loop de monitoramento.
